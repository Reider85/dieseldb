3.1.18 Prompt 54 - JSONL parallel read via byte-offset pre-scan

New public diesel/storage/JsonlParallelLoader: one byte-level pass splits
physical lines exactly like BufferedReader.readLine (\n, \r\n, lone \r),
detects BOM and blank lines, records every data-line start offset into a
LineIndex cached by path+mtime+size. Plain-text loads are partitioned into
ByteRangeTask ranges over those offsets, read concurrently on a daemon
ForkJoinPool and merged deterministically in file order. Each partition has
a thread-confined JsonlSchemaManager and returns its nestedColumnIndexes;
loadParallel unions them so JsonlRowStorage replays the nested-JSON holder
marks onto the shared schema manager (prevents double-encoding on save).
Fallbacks to the sequential reader: compressed files, files below
jsonl.parallel.read.threshold (sysprop -> config.properties -> default
10000), and > Integer.MAX_VALUE lines.

- JsonlRowReader: initPartition(long firstDataLine, boolean atFileStart),
  setSuppressSkipSummary(boolean) so per-partition skip WARNINGs collapse
  into one merged summary; sequential behaviour unchanged.
- JsonlIndexManager: loadFromFileParallelArrays(...), cached preScan(File),
  parallelReadThreshold().
- JsonlRowStorage: parallel branch when the codec is none, all-true presence
  fallback, nested-mark replay into sharedSchemaManager.
- config.properties: jsonl.parallel.read.threshold = 10000.
- New JsonlParallelLoadTest (7 fast tests + @LargeTest 1M rows).

Verification: Prompt-54 tests 8/8 pass; 1M-row acceptance seq=3311ms vs
