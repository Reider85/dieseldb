# Prompt 65: AVRO Deflate compression levels - adaptive selection and compressor caching

**Date:** 2026-09-19

## Implemented

### DeflateLevelConfig (diesel/storage/avro/DeflateLevelConfig.java) — new
- Level range 1-9 with -1 resolving to default level 3 (balanced speed/ratio)
- `resolveLevel(int)`: clamps sub-range (0, -5 → 1) and over-range (10, 99 → 9) with WARN logging
- `newCodec(int)`: returns Avro `CodecFactory.deflateCodec(resolvedLevel)`
- `selectOptimalLevel(long dataSize, String dataType, boolean isStreaming)`: adaptive level selection by payload size, data type and streaming mode
- `estimateCompressionRatio(int, String)`: heuristic ratio per level × data type
- `analyzeTradeoff(int)`: human-readable level description
- Borrow/return `Deflater`/`Inflater` pools: bounded per-level (`Deflater`) and shared (`Inflater`) caches, `clearCache()` releases native resources, `getCacheStats()` summary string
- Config resolved sysprop → config.properties → code default: `avro.deflate.cache.compressors = on`, `avro.deflate.cache.max.size = 10`

### AvroCodecFactory (diesel/storage/avro/AvroCodecFactory.java) — updated
- Deflate case now delegates to `DeflateLevelConfig.newCodec(level)` instead of raw `CodecFactory.deflateCodec(resolveDeflateLevel(level))`
- Removed duplicated DEFLATE_MIN_LEVEL/DEFLATE_MAX_LEVEL constants and private `clamp()` helper
- `resolveDeflateLevel(int)` now delegates to `DeflateLevelConfig.resolveLevel()`
- Javadoc updated: level 1-9 range, DeflateLevelConfig reference, enhanced in Prompt 65

### config.properties — updated
- `avro.deflate.adaptive = off` (reserved for future adaptive mode)
- `avro.deflate.strategy = balanced` (reserved for strategy hint)
- `avro.deflate.cache.compressors = on` (compressor/decompressor caching)
- `avro.deflate.cache.max.size = 10` (pool cap per level)

### Tests
- `DeflateLevelConfigTest` (14 tests, @Tag("storage")): level resolution/clamping, newCodec round-trip, selectOptimalLevel (streaming/size/type), analyzeTradeoff coverage, estimateCompressionRatio monotonic + bounded, Deflater/Inflater pool borrow/return reuse + cap + clearCache, cache-disable sysprop, cache stats
- `DeflateCompressionBenchmarkTest` (1 test, @Tag("storage")): benchmark across levels 1/3/5/7/9 for text/repetitive/numeric, asserts compressed ratio is monotonically non-increasing with higher levels
