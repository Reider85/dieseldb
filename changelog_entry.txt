3.1.44 Prompt 75: AVRO schema - complex types - ARRAY/MAP/RECORD/ENUM support

New diesel/storage/avro complex-type handlers (@since Prompt 75): AvroArrayHandler (List/Collection/Object[] - toAvroArray wraps an array schema with a nullable STRING element default empty, gets/sets size + element via GenericData.Array, validates avro.array.max.size limit, fromAvroArray returns List), AvroMapHandler (Map<String,Object> with avro.map.max.size limit; MAP schema is map<string> (nullable string values), toAvroMap/fromAvroMap keep keys as Strings, null keys rejected before indexing), AvroRecordHandler (nested RECORD with group-name schema, field name/value maps, recursion guard via ThreadLocal stack of full names, avro.record.max.nesting.depth default 10, fromAvroRecord returns a Map<String,Object>), AvroEnumHandler (GenericData.EnumSymbol with symbol set mirrored in the schema; canonizes by avro.enum.case.sensitive (default false -> 'active'->'ACTIVE'), isValidSymbol, rejects invalid symbols within a union branch. Registered in scripts/tia-mapping.txt (5 files -> storage-avro) and scripts/tag-mapping.tsv (AvroComplexTypeTest -> storage). AvroTypeMapper grows the schema mapping for ARRAY (List/ArrayList/LinkedList/Collection -> array of nullable string) and MAP (Map/HashMap/LinkedHashMap/TreeMap -> map<string>) plus toPrimitiveJavaType/toJavaType ARRAY->List.class/MAP->Map.class, typeName List->ARRAY/Map->MAP, typeClass ARRAY->List/MAP->Map, and createArray/createMap/createEnum delegating into the new handlers. AvroUnionHandler.valueMatchesBranch matches CharSequence/enum symbols to the ENUM branch and Map to the RECORD branch, primitiveTypeOf maps Object[]->ARRAY.
