## JavaDoc style guide (matching existing conventions)
```java
/**
 * Short description of what this class/method does.
 *
 * <p>Detailed behavior description if needed.
 *
 * @param paramName description of parameter
 * @return description of return value
 * @throws ExceptionType when this exception is thrown
 * @see OtherClass#relatedMethod
 */
```
For priority files, include `@code` examples:
```java
/**
 * Example:
 * <pre>{@code
 * Database db = new Database("data");
 * db.executeQuery("CREATE TABLE T (ID INTEGER)", null);
 * }</pre>
 */
```
