- **In-memory mode**: `CliRepl --local [dataDir]` — creates `Database(dataDir)` directly, executes queries without a server.

REPL loop:
```
while (true):
  print "diesel> "
  read line from BufferedReader(System.in)
  if null / empty / "EXIT" / "QUIT" → disconnect + break
  if "HELP" → print usage
  try: result = client.executeQuery(line) / database.executeQuery(line, null)
  catch: print error
  print result (format List<Map> as table, null as "OK", String as-is)
```
