## About DieselDB

DieselDB is an open-source, file-persisted SQL database engine written entirely in Java. It's designed for applications that need a simple, embedded database without the complexity of traditional RDBMS. Key features include:

- **File-based storage**: CSV, TSV, JSONL, AVRO formats
- **SQL interface**: Full JDBC compatibility
- **MVCC & SSI**: Multi-version concurrency control with serializable isolation
- **WAL-based**: Write-ahead logging for crash recovery
- **Auto-releases**: Every push creates a new release (v3.4.x-build.N)
- **Cross-platform**: Works on Windows, macOS, Linux
